# data (데이터)

## 현재 상태
- 1단계 진행 중: AI Hub 「벼 생육이상 인식 데이터」 정리 완료, RGB 오픈 데이터 조사 전
- AI Hub 데이터는 다분광(5밴드)이고 공개 모델 입력이 G·N·E라서 **RGB에 그대로 쓸 수 없음**

## 결정된 것
- RGB 데이터 사용 (거의 확정)
- 직접 라벨링 불가 → 오픈 데이터 활용

## 다음 할 일

- 팀원 보유 태국 BLB 데이터 정보 받아서 기록 (출처, RGB 여부, 라벨 형태)

## 조사 메모
- AI Hub 데이터 상세와 공개 모델 테스트 결과: [model/README.md](../model/README.md)
- 검토 중인 방향(결정은 기획·관제실에서): ① AI Hub 데이터의 R·G·B 밴드로 재학습 ② 다른 RGB 데이터 찾기 → 여러 데이터 혼합
- 데이터 혼합 시 주의: 촬영 거리(해상도) 차이가 크면 고해상도 쪽을 줄여서 맞춰야 함, 라벨 형태·클래스 이름 통일, 평가는 데이터별로 따로
- 확인 필요: 해상도 표기 차이(6.63cm / 6.8cm), AI Hub 페이지 수치 불일치(전체 mAcc 77.44% vs 86.69%)

※ 실제 이미지 파일은 저장소에 올리지 않습니다 (`data/raw/`, `data/processed/`는 자동 제외).
