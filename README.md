# 드론 영상 기반 벼 병해 탐지 모델 개발 및 웹 서비스 제공

차세대통신사업단 캡스톤 프로젝트 (기업 협업: 터빈크루)

## 현재 단계
**1단계: 오픈 데이터 조사** — 정리 완료
- 일반 RGB로 찍은 벼 병해 드론 데이터는 공개된 것이 거의 없음 → 다분광 데이터(AI Hub, 태국 BLB)에서 R·G·B를 뽑아 쓰는 방향
- 조사표: [data/README.md](data/README.md)
- 다음: 2단계(탐지 단위·정량 목표 결정)

## 전체 워크플로우
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 오픈 데이터 조사 | 완료 |
| 2 | 탐지 단위·정량 목표 결정 | 대기 |
| 3 | 기본 모델 학습 (작게 시작) | 대기 |
| 4 | 웹 시제품 (가짜 데이터로 먼저, 3단계와 병행 가능) | 대기 |
| 5 | 드론 + 시스템 검증 (부품 도착 후) | 대기 |

자세한 일정: [planning/schedule.md](planning/schedule.md)
결정 사항: [planning/decisions.md](planning/decisions.md)
AI 활용 기록: [planning/ai-log.md](planning/ai-log.md)

## 폴더 안내
| 폴더 | 역할 |
|---|---|
| `planning/` | 기획 — 결정 사항, 일정, 회의 메모 |
| `data/` | 오픈 데이터 조사 결과, 데이터 설명 (실제 이미지는 올리지 않음) |
| `model/` | 탐지 모델 학습 코드와 실험 기록 |
| `web/` | 웹 서비스 코드 |
| `drone/` | 부품 목록, 조립·자율주행 기록 |
| `validation/` | 검증 계획 (모델 검증 / 대체 비행) |

각 폴더의 README에는 **현재 상태 / 결정된 것 / 다음 할 일**을 적습니다.
