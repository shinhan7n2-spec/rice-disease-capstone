# 드론 영상 기반 벼 병해 탐지 모델 개발 및 웹 서비스 제공

차세대통신사업단 캡스톤 프로젝트 (기업 협업: 터빈크루)

## 현재 단계
**1단계: 오픈 데이터 조사** — 어떤 벼 병해 데이터를 쓸 수 있는지 확인 중
- AI Hub 「벼 생육이상 인식 데이터」 정리 및 공개 모델 테스트 재현 완료 → 다분광(G·N·E) 입력이라 RGB에 그대로 사용 불가
- 다음: RGB 벼 병해 오픈 데이터 조사, 태국 BLB 데이터 정보 수집
