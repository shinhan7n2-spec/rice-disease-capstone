# model (탐지 모델)

## 현재 상태
- 데이터 결정 대기 중
- AI Hub 공개 모델(SegFormer-B4) 테스트 재현 완료 → 입력이 G·N·E라 RGB 드론 영상에 그대로 사용 불가

## 결정된 것
- 입력: RGB (거의 확정)
- 방식: YOLO 객체 탐지, 박스 형식 (임시)
- 학습 환경: AWS 무료 크레딧 (임시)
