# 결정 사항

표기: **확정** / **거의 확정** / **임시** / **미정**

## 모델
| 항목 | 내용 | 상태 |
|---|---|---|
| 입력 데이터 | RGB (다른 방식은 비싼 카메라가 필요해 불가능) | 거의 확정 |
| 모델 방식 | YOLO 객체 탐지 (박스 형식) | 임시 |
| 라벨링 | 직접 라벨링 불가 (병해 구분이 어려움) → 오픈 데이터 적극 활용 | 확정 |
| 학습 환경 | 팀에 NVIDIA GPU 없음 → AWS 무료 계정 첫 크레딧 사용 (무거운 작업 주의) | 임시 |
| 정량 목표 | 어느 정도 성능을 목표로 할지 | 미정 |

## 웹
| 항목 | 내용 | 상태 |
|---|---|---|
| 기능 | 지도 표시, 병해 정보 조회, 오탐 수정, 자율주행 설정 | 임시 |

## 드론
| 항목 | 내용 | 상태 |
|---|---|---|
| 프레임 | F450 조립 | 확정 |
| 무게 | 어려운 자격증 없이 온라인 교육 이수만으로 조종 가능한 무게 | 확정 |
| 부품 | 대부분 선정, 일부 미구매 | 진행 중 |
| 카메라 | 아직 고르지 못함 | 미정 |
| 우선순위 | 부품 주문 단계라 나중에 다루고, 지금은 다른 작업에 집중 | 확정 |

## 검증
| 항목 | 내용 | 상태 |
|---|---|---|
| 제약 | 벼 수확 시기가 지나 실제 논 촬영 불가 | 확정 |
| 방식 | 모델은 병해 데이터로, 시스템은 대체 비행으로 나눠서 검증 | 임시 |

## 남은 문제
1. RGB 데이터 확보와 탐지 단위 결정
2. 드론 촬영 조건과 모델 입력의 적합성
3. 현장 시험을 대신할 검증과 시스템 연결·구현
4. 정량적 목표 설정
