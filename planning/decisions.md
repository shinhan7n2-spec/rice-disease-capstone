# 결정 사항

표기: **확정** / **거의 확정** / **임시** / **미정**

## 모델
| 항목 | 내용 | 상태 |
|---|---|---|
| 입력 데이터 | RGB (다른 방식은 비싼 카메라가 필요해 불가능). 학습 데이터는 다분광 데이터에서 R·G·B만 뽑아 색을 맞춰 사용 | 거의 확정 |
| 병해 범위 | 도열병, 흰잎마름병(BLB), 낟알 변색, 도복, 정상으로 시작. 불가능하다고 판단되면 그때 데이터 추가 (공개 드론 병해 데이터가 이 범위뿐 — [data/README.md](../data/README.md)) | 임시 |
| 모델 방식 | 분할(YOLO-seg 등)과 박스(YOLO) 둘 다 작게 실험해 보고 결과로 결정 (공개 데이터 라벨이 대부분 분할) | 미정 (3단계 실험으로 결정) |
| 라벨링 | 직접 라벨링 불가 (병해 구분이 어려움) → 오픈 데이터 적극 활용 | 확정 |
| 학습 환경 | 팀에 NVIDIA GPU 없음 → AWS 무료 계정 첫 크레딧 사용 (무거운 작업 주의) | 임시 |
| 정량 목표 | 공개 모델 대비 상대 목표 (예: 도열병 IoU를 AI Hub 공개 모델 9.14보다 높게) | 거의 확정 |

## 웹
| 항목 | 내용 | 상태 |
|---|---|---|
| 기능 | 지도 표시, 병해 정보 조회, 오탐 수정, 자율주행 설정 | 임시 |

## 드론
| 항목 | 내용 | 상태 |
|---|---|---|
| 프레임 | F450 조립 | 확정 |
| 무게 | 어려운 자격증 없이 온라인 교육 이수만으로 조종 가능한 무게 | 확정 |
| 부품 | 대부분 선정, 일부 미구매 | 진행 중 |
| 카메라 | 아직 고르지 못함 | 미정 |
| 우선순위 | 부품 주문 단계라 나중에 다루고, 지금은 다른 작업에 집중 | 확정 |

## 검증
| 항목 | 내용 | 상태 |
|---|---|---|

## 협업
| 항목 | 내용 | 상태 |
|---|---|---|
| 터빈크루 문의 | 병해 범위·탐지 방식·정량 목표 결과가 나온 뒤 그 결과를 근거로 질문 (원하는 병해 우선순위, 보유 드론 영상 여부 등) | 확정 |
