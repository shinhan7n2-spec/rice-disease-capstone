# 워크플로우와 일정

순서: **데이터 → 모델 → 웹 → 드론**
(데이터가 정해져야 탐지 단위, 모델 방식, 정량 목표, 드론 카메라 조건이 정해짐)

## 1단계. 오픈 데이터 조사
- 벼 병해 오픈 데이터 위치와 형태 정리
- 확인할 것: 박스 라벨 여부 / 근접 촬영인지 항공 촬영인지 / 병해 종류 / 이미지 수

## 2단계. 탐지 단위·정량 목표 결정
- 공개 데이터 라벨이 대부분 분할(영역) → 분할과 박스를 3단계에서 비교 실험 후 결정
- 정량 목표 예: 탐지 정확도 점수(mAP) 기준, 처리 시간 기준
- 터빈크루 측 기대 수준 확인 (1~3단계 결과를 근거로 질문)

## 3단계. 기본 모델 학습
- 데이터 일부로 작게 시작해 작동 확인 (AWS 크레딧 절약)
- 실험 항목: 분할 vs 박스 / 색 맞추기·해상도 맞추기·색 증강 / RGB만 vs RGB+식생지수 ([model/README.md](../model/README.md))

## 4단계. 웹 시제품 (3단계와 병행 가능)
- 가짜 결과 데이터로 지도 표시, 병해 정보 조회, 오탐 수정 먼저 구현

## 5단계. 드론 + 시스템 검증
- 카메라는 1~2단계 결과(필요 해상도, 비행 높이)를 보고 선택
- 대체 비행으로 촬영 → 업로드 → 모델 → 웹 지도 표시가 이어지는지 확인
